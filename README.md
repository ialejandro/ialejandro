## About me

I'm a Platform Engineer based in Spain. I build and run cloud infrastructure for startups and scale-ups, mostly AWS with Terraform and Kubernetes, and I plug into whatever CI/CD tool the team already uses. I like platforms that stay reliable and don't surprise anyone on the monthly bill.

When I find a tool I keep needing, I package it and open source it under [devops-ia](https://github.com/devops-ia).

## What I do

- **Cloud architecture and migration**: design, zero-downtime moves, FinOps, security and compliance.
- **Kubernetes and GitOps**: cluster design, ArgoCD, service mesh, monitoring.
- **Modernization**: assess legacy systems, containerize them, move them to cloud-native.
- **DevOps strategy and pipelines**: CI/CD, infra architecture, helping teams ship faster.

Want to work together? Find me on [Malt](https://www.malt.es/profile/ivanalejandromarugan) or [write me](mailto:projects@ialejandro.rocks).

### Platforms and tools

| Project | What it does | Stack |
|---|---|---|
| [dwpk](https://github.com/devops-ia/dwpk) | Persistent dev workspaces on your own cluster, reachable from the browser or SSH, from a catalog you control | Go, Kubernetes operator |
